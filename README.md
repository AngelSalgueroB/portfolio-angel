# Angel Salguero - Full Stack Systems Engineer Portfolio - SS-Dev

> Source code for my professional interactive web portfolio.

As a Systems Engineer, this project serves not only as a frontend showcase but as a reflection of my comprehensive approach to software development. My expertise spans the entire software lifecycle: from architectural design, data integration, and systems auditing, to building scalable, user-centric applications applying clean code principles.

## Core Competencies & Expertise

* **Systems Engineering:** IT Infrastructure, Systems Auditing, Network Fundamentals, Technical Research, and IT Project Management.
* **Software Engineering:** Object-Oriented Programming (started with Java), Full Stack Web/Mobile Development, Clean Code, and Software Architecture best practices.
* **Data & AI:** Data Integration, ETL pipelines, Python (Pandas) for data manipulation, and Artificial Intelligence API integrations.
* **Database Management:** Relational database design, performance tuning, SQL, and PostgreSQL.
* **Product Design:** UI/UX principles applied to enterprise software, focusing on functional, accessible, and high-performance interfaces.

## Portfolio Key Features

* **Bilingual Architecture (EN/ES):** Native internationalization managed through a centralized translation structure.
* **Integrated Project Simulations:** Interactive demos (GPS Fleet Tracking, Retail E-Commerce, POS Systems) rendered dynamically in modals, demonstrating complex logic without external routing.
* **Dynamic Theming:** Dark Mode by default with a customizable accent color selector that injects semantic variables directly into the DOM.
* **Reactive Terminal:** Realistic command-line animation for presenting metrics, mimicking real server logs.
* **AJAX Form Handling:** Direct email submission payload processing without page redirects.
